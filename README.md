# 🐍 100 Days of Python

My journey through the **100 Days of Code: The Complete Python Pro Bootcamp** by Dr. Angela Yu.

This repository contains the exercises and projects I develop throughout the course as I improve my Python programming skills.

## 📚 About the Course

The course focuses on learning Python through hands-on exercises and practical projects, progressing from programming fundamentals to more advanced concepts.

## 🛠️ Technologies & Tools

- **Python** — Programming language
- **PyCharm** — Development environment
- **Git & GitHub** — Version control and project hosting

## 📖 Topics Covered

- Variables and data types
- Strings and mathematical operations
- Conditional statements and loops
- Functions and data structures
- Object-Oriented Programming (OOP)
- Working with APIs
- Automation
- Application development

## 🚀 Featured Projects

| Project | Description | Concepts |
|---|---|---|
| ☕ Coffee Machine | A coffee machine simulation | Functions, modules, and OOP |
| 🧠 Quiz Game | A quiz game with questions and score tracking | Classes, objects, and logic |
| 🐢 Turtle Race | A turtle racing game with user bets | Turtle Graphics, loops, and user input |
| 🐍 Snake Game | A classic Snake game | OOP, keyboard input, and collision detection |
