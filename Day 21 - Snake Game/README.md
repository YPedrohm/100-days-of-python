\# 🐍 Snake Game



A classic Snake Game developed in Python as part of the 100 Days of Code: The Complete Python Pro Bootcamp.



\## About the Project



The goal is to control the snake, eat food, increase your score, and avoid collisions with the walls and the snake's own body.



\## Features



\- Snake movement using the arrow keys

\- Food generation

\- Snake growth after eating

\- Score tracking

\- Wall and self-collision detection

\- Game over screen



\## Technologies



\- Python

\- Turtle



\## How to Run



1\. Install Python.

2\. Download or clone this repository.

3\. Open a terminal in this folder.

4\. Run:



```bash

python main.py

```



\## Controls



| Key | Action |

|---|---|

| ↑ | Move up |

| ↓ | Move down |

| ← | Move left |

| → | Move right |
