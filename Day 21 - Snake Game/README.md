# 🐍 Snake Game

A classic Snake Game developed in Python as part of the **100 Days of Code: The Complete Python Pro Bootcamp** course.

## 📌 About the Project

The goal is to control the snake, eat food, increase the score, and avoid colliding with the walls or the snake's own body.

## ✨ Features

- Snake movement using the arrow keys
- Food spawning at random positions
- Snake growth after eating food
- Score tracking
- Wall and self-collision detection
- Game Over screen

## 🛠️ Technologies

- Python
- Turtle Graphics

## 🚀 How to Run

1. Install [Python](https://www.python.org/downloads/).
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

## 🎮 Controls

| Key | Action |
|---|---|
| ↑ | Move up |
| ↓ | Move down |
| ← | Move left |
| → | Move right |
